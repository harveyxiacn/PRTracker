## Starting point (baseline screenshots)

## Decisions
- **Home order:** abroad banner → critical alerts → citizenship hero → residency → PR card → quick actions
  → other alerts (2 + *Show N more*) → processing-time alerts → household → applications → year strip →
  reminders. The e2e test reads residency/PR-card sentences on Home, which also matches the "answer the
  real question" principle, so those stay visible; only explanations moved into `<details>`.
- **Undo over confirm** for trip deletion (mobile pattern: recover instead of interrupt). Undo restores the
  saved trip, not an unsaved draft, and does nothing if the trip is already back.
- **Sheet exit animation lives inside `Sheet`:** close button / Escape / backdrop / drag call
  `requestClose`, which plays a 180 ms exit and then calls `onClose`. A parent unmounting the sheet
  (after Save) is not delayed. A second close during the exit is ignored; if the parent keeps the sheet
  open, it reappears rather than staying invisible. Reduced motion closes immediately.
- **Drag handle only** (grabber + title row, `touch-action: none`) so scrolling forms and selecting text
  never move the sheet. Thresholds: 25 % of height or 0.6 px/ms.
- **Screen transition is opacity-only:** a transform on the screen wrapper would become the containing
  block for `position: fixed` children (Maple composer) during the animation.
- Toast lengths 4 s / 6 s with an action; the live region stays mounted so each message is announced.
- All timings are proposals tuned on desktop emulation, not measured on a device.

## Second pass (same day): Calendar, Timeline, Settings → v0.9.0
- PR #2 (review fixes + first pass) passed CI (web, screenshots, debug APK) and was merged to main.
  The user decided to ship everything as one release after this second pass.
- **Calendar:** toolbar moved into the card (Year/Month, arrows, *Today* only when away from today).
  `useSwipe` (ui.tsx) pages on a horizontal touch swipe ≥ 48 px that is clearly more horizontal than
  vertical; mice don't swipe (they'd fight text selection) and `touch-action: pan-y` keeps vertical
  scrolling native. The page is keyed by period so it slides in from the side it came from. Month
  names in the year view are buttons that open the month. The selected day gets *Add trip* / *Edit
  trip* (re-uses the Trips editor sheet).
- **Timeline detail** reordered answer-first; the edit form is a `<details>` that starts open only for
  unsubmitted applications (the e2e test now opens it). Next step = first milestone without a date
  once submitted (`aria-current="step"`, 3 soft pulses, none under reduced motion). Delete → Undo
  restores the application at its index plus its document checklist.
- **Settings:** `Toggle` = native checkbox with `role="switch"` (keyboard/labels for free). Section
  index chips scroll and move focus to the section heading. Wipe moved to a *Danger zone* card; it keeps
  its confirm because there is nothing to undo to.
- **Bundle:** the entry went to 140.4 kB with this pass. `LockScreen` was the only static import of
  `screens/Security` (biometrics, PIN hashing, ICS, backup restore) → lazy, with a blank fallback so
  nothing behind the lock is drawn. Entry now 135.5 kB.
- 9 more strings translated into 18 languages (one sonnet agent, validator OK).
- New e2e: application undo, PIN lock after reload.
