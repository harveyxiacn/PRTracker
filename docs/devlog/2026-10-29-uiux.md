## Decisions
- **Home order:** abroad banner → critical alerts → citizenship hero → residency → PR card → quick actions
  → other alerts (2 + *Show N more*) → processing-time alerts → household → applications → year strip →
  reminders. The e2e test reads residency/PR-card sentences on Home, which also matches the "answer the
  real question" principle, so those stay visible; only explanations moved into `<details>`.
- **Undo over confirm** for trip deletion (mobile pattern: recover instead of interrupt). Undo restores the
  saved trip, not an unsaved draft, and does nothing if the trip is already back.
- **Sheet exit animation lives inside `Sheet`:** close button / Escape / backdrop / drag call
  `requestClose`, which plays a 180 ms exit and then calls `onClose`. A parent unmounting the sheet
  (after Save) is not delayed. A second close during the exit is ignored; if the parent keeps the sheet
  open, it reappears rather than staying invisible. Reduced motion closes immediately.
- **Drag handle only** (grabber + title row, `touch-action: none`) so scrolling forms and selecting text
  never move the sheet. Thresholds: 25 % of height or 0.6 px/ms.
- **Screen transition is opacity-only:** a transform on the screen wrapper would become the containing
  block for `position: fixed` children (Maple composer) during the animation.
- Toast lengths 4 s / 6 s with an action; the live region stays mounted so each message is announced.
- All timings are proposals tuned on desktop emulation, not measured on a device.
