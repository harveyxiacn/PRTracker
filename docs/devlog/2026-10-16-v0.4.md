## What visual QA found (the first time the UI was actually looked at)
- **Every unsized icon stretched to the full card width.** Home had giant flag, shield, card and bell icons, and the "Add trip" button had a huge plus. Unit tests could never catch this. Fixed with a 20px default plus CSS guards.
- Arabic calendar month names were in English (a hard-coded `en-CA`/`zh-CN`).
- The Maple greeting was English in Hindi, because it was built before the language chunk loaded.
- Demo data had English labels overriding translated names.
The second run confirmed every fix in EN, 中文, العربية and हिन्दी.
