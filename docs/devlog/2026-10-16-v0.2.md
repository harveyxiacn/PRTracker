# Dev log — 2026-10-16 (v0.2: global users)

## Ask
Users are applicants from all over the world, applying through Express Entry, provincial nomination and other programs. That means more languages, more programs, and timelines from Reddit and CanadaVisa. The user shared three real Reddit posts to build the parser against, and asked for Opus subagents to work in parallel.

## Decisions
| Decision | Why |
|---|---|
| One **program catalogue** drives templates, fallback times, IRCC data series, links and status | Adding a program is one row plus strings, and tests keep the community validator in sync |
| **No scraping** of Reddit or CanadaVisa | Reddit returns 403 without its API; CanadaVisa sits behind Imperva bot protection, with copyright/ToS risk. We link out to searches and let *people* paste what they read; the parser runs on the device |
| Parser built from **real posts** | The three samples exposed "CEC Inland" vs spousal-inland, story sentences with dates, P1/P2, "Stream:" lines, PVO/SVO, year-less dates. The review added more: "LABEL - date", MM/DD posts, 2-digit years, base PNP |
| **Rule-based Maple v2** instead of an LLM | Exact and private. The new value comes from treating the user's data as a database plus planners on the presence engine. FAQ answers are curated text with sources |
| **14 languages**, lazy-loaded, translated by 5 parallel Opus agents from a shared brief, with Maple lexicons in each | Covers the largest source countries; the parity test guarantees completeness |
| **Facts verified on canada.ca** before shipping | Caught: police certificates (10 years, not "since 18"), biometrics (every PR application), caregiver pilots paused (notice of 2025-12-19), Start-up Visa paused, PEQ status changing |

## Agents (Opus)
- Translators: zh delta + zh-Hant; fr/es/pt; hi/pa/ur; ar/fa; tl/vi/ko. All reached 655/655 keys with matching placeholders. Each also caught engine gaps for its script: Traditional Chinese 兩/下週/國外; the single-letter units "j"/"d", where "5 de mayo" would have read as 5 days; the ambiguous Hindi "kal".
- Reviewer: hand-ported the pure modules to .mjs and **ran** realistic inputs; 22 confirmed defects, all fixed with regression tests (`review2.test.ts`).

## Numbers
- Tests: 49 → 102 (domain, parser, planner, assistant, i18n parity for 13 locales, catalogue/validator sync).
- Bundle: 430 KB main (138 KB gzipped); each language is a separate 40–90 KB chunk.
