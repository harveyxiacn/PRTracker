# Dev log — 2026-10-16 (day 1)

## Goal
Build a privacy-first app for Canadian PR holders and applicants: eligibility, timeline
logging and prediction, citizenship and PR-card countdowns, an in/out heat-map calendar and
travel logging with back-dating. It should run on Android, iOS and the web, keep data local,
and use GitHub for version control, CI and releases. It also includes a small smart assistant.

## Decisions
| Decision | Why |
|---|---|
| **React + TypeScript + Vite + Capacitor 7** (one codebase → PWA, Android, iOS) | Flutter wasn’t installed on the workstation, while Node was. Capacitor gives native notifications and storage, and the web build doubles as the iOS fallback without an Apple account. |
| **No backend; local storage only** | The data is sensitive; local-first removes a whole class of privacy risk. IndexedDB on web, Preferences on native. Android `allowBackup=false`. |
| **Day-number arithmetic (UTC)** and **prefix sums** | Correctness: no DST/time-zone bugs. Speed: O(1) 5-year window queries make what-if simulation instant. |
| **Border days count as present** (toggle for strict) | Matches IRCC’s counting; the strict mode lets cautious users see the worst case. |
| **Residency “must return by” verified by brute force in tests** | The rolling-window and “< 5 years” rules are easy to get off by one. Tests rebuild the model with a real return date and check every day for a year. |
| **Rule-based assistant (“Maple”)** instead of an LLM | Answers must be exact and private. Intents + entity parsing in EN/中文 on top of the same engine. |
| **Community timelines through GitHub issues + workflow** | No server needed; reviewable, anonymised (month precision), CC0. App reads a static JSON. |
| **IRCC processing-time mirror via scheduled Action** | canada.ca JSON has no CORS for browsers. A daily job normalises it into `public/data/ircc.json` on Pages. |
| **CRS without job-offer points** | Removed by IRCC on 2025-03-25. |
| **PR card renewal at 9 months** | IRCC: apply when the card expires within 9 months (verified on canada.ca). |

## Research notes
- IRCC `data-ptime-non-country-en.json` exposes PR card (`existing_pr`, e.g. “38 days”), citizenship sub-types and others. PR program keys vary, so the mirror maps by pattern and logs the mapping.
- canada.ca timed out from the control host and the workstation bridge (HTTP/2 stream errors), so the mirror runs in GitHub Actions.
- Express Entry processing service standard is 6 months; spousal and citizenship are 12 months (used only as an offline fallback).

## First CI run & independent review
- First push: CI (typecheck, tests, web build, **Android debug APK 4.2 MB**), Pages deploy and the data refresh all passed.
- IRCC's public JSON currently has the PR card time only (`existing_pr` = 38 days); Express Entry, PNP, spousal and citizenship-grant times aren't published there, so those use service-standard fallbacks until community data arrives.
- The data workflow didn't commit new files (`git diff` ignores untracked files). Fixed by staging first and diffing `--cached`.
- A read-only review by a second agent produced 27 findings; 26 were fixed and 1 was rejected:
  - **UI:** the bottom sheet stole focus on every keystroke; number inputs couldn't be cleared or take “6.”; the data-URL field fetched on every keystroke.
  - **Data safety:** the last edit within 250 ms of closing could be lost (now flushed on `pagehide`/`visibilitychange`); unreadable stored data is kept under a `.corrupt.*` key instead of being overwritten; `migrate()` now repairs nested fields; insights can’t blank the app.
  - **Rules:** ongoing-trip length was off by one; nested overlapping trips were missed; years before arrival showed as “in Canada”; a trip in progress with a known return wasn’t “abroad now”; reminders dated today were dropped.
  - **Assistant:** removed the substring `ee`→CRS and “landed”→return misfires; Chinese `3月5日` is no longer read as “3 months”; max-absence questions route to residency; past dates are used when logging trips; handles curly apostrophes; double-tapping *Log this trip* no longer duplicates trips.
  - **Workflows:** Pages wasn’t redeployed after data/community commits (needs `actions: write`); release signing condition; manual release runs are limited to tags; community JSON is now written one record per line so diffs work.
  - **Rejected:** “CRS single age 18/19 should be 90/95.” IRCC’s table is 99/105 without a spouse (90/95 is with a spouse).
- Tests: 38 → 49.
