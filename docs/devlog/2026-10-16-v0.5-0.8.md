## Decisions
- **One release (0.8.0) for four roadmap milestones.** They were built in parallel on a branch and only make sense together (Home merges cross-checks and alerts; translations were done in one pass).
- **Biometrics never replace the PIN.** The PIN pad stays visible; `allowDeviceCredential` is off so the device passcode can't bypass the app PIN.
- **CBSA text is parsed, not stored.** The parser is format-agnostic (no official sample layout exists); ambiguous dd/mm dates are skipped rather than guessed.
- **Curves only count finished timelines** and say so in the UI, because that makes them look slightly faster than reality.
- **Bundle budget:** the first build was 144 kB gzip, over the new 140 kB limit. Lazy-loading the CBSA sheet and the processing-alerts card brought it to 137 kB.
- **Generic lexicon phrases pruned.** Translators flagged words like "what percent", "my absences", "physical presence" that would steal CRS/residency questions. The lead removed the broadest ones and added guards in the engine.

## Lessons
- English kept growing while the new-language translators worked, so most of them finished 218 keys short. Next time: freeze `en` + parts before starting translators, or start them last.
- Several agents' key checkers missed prefixes with digits (`a11y.`, `c2.`). The vitest parity test is the source of truth.
- Agents can't run tsc/vitest on the control host; giving them the PC test-job recipe would save the lead a round trip.

## QA findings fixed (0 critical, 11 medium/low)
- A received person named with the default "Me" could replace your own data → the default name never matches; the receiver names the person.
- Print did nothing in the Android/iOS WebView → the app shares the report as an HTML file there.
- Approving several timelines at once cancelled queued intake runs → one concurrency group per issue, push retried after a rebuild.
- Abroad with an expired PR card gave no warning; a renewed card in Documents was ignored → both fixed.
- Exits-only CBSA paste flagged every trip; strict-mode ongoing trip was a day short; overlapping trips double-counted in the absence total → fixed, with tests.
- Biometric unlock could be enabled without a biometric check; "Got it" on alerts could hide same-day changes; sheets focused the Close button first → fixed.
- Left as known: a CBSA entry 2+ days away from a logged return is proposed as a new trip (the review list shows it before anything is added).
